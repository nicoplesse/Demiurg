# Power Engineering

Dieser Ordner beschreibt nicht nur, welche Powers existieren, sondern wie sie technisch, biologisch und energetisch funktionieren.

## Zweck

- charakterspezifische Mechanismus-Stacks dokumentieren
- Powerscaling nachvollziehbar machen
- Betriebsmodi und Limits festhalten
- physikalische Probleme nicht pauschal loesen
- verhindern, dass die demiurgische Schicht als beliebige Magie benutzt wird

## Trennung

| Ordner | Zweck |
|---|---|
| physics/ | allgemeine Probleme |
| power-system/ | globale Regeln |
| power-engineering/ | charakterspezifische Loesungen |
| power-profiles/ | Zusammenfassungen und Messwerte |
| characters/ | Figur, Persoenlichkeit, Beziehung |

## Grundregel

Keine relevante Faehigkeit ohne Mechanismus-Stack.

Jede Faehigkeit braucht:
- Domaene
- Energiequelle
- gewuenschtes Scaling
- physikalisches Problem
- biologisches Problem
- Umweltproblem
- demiurgischen Mechanismus
- Kosten
- Limits
- Betriebsmodi
- Plot-Regeln
