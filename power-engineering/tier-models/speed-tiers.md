# Speed Tiers

## Zweck

Diese Datei definiert interne Arbeitskategorien fuer Geschwindigkeit.

## Wichtig

Geschwindigkeit muss getrennt werden in:
- Travel Speed
- Combat Speed
- Reaction Speed
- Perception Speed
- Attack Speed
- Burst Speed
- Safe Urban Speed
- Flight Speed

## Arbeitsrange fuer alte Riege

Die alte Riege kann je nach Charakter und Modus extreme Bereiche erreichen.

Fuer Apollon ist als Arbeitsrange Hypersonic bis Sub-Relativistic+ vorgesehen.

## Regel

Ein Charakter kann in einer Kategorie hoeher liegen als in einer anderen.

Beispiel:
Reaction Speed kann hoeher sein als Safe Urban Speed.
Burst Speed kann hoeher sein als Combat Speed.
Travel Speed kann andere Grenzen haben als Attack Speed.
